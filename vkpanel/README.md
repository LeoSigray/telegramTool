# VK-панель: привлечение курьеров Яндекс Еды

Отдельная система для двоих (владелец и Сергей). Не связана с Mini App «Клиент в один клик»: свой Telegram-бот,
своя служба `telegramtool-vkpanel`, своя база `data/vk.db`, свои настройки. Для покупателей Mini App её не существует.

## Как это работает
1. **Аккаунты VK** (покупаются на DarkStore) пишут в личные сообщения людям. Это обычные пользовательские аккаунты с токенами:
   сообщество-бот в VK первым написать человеку не может, поэтому «бот» здесь только пульт управления в Telegram.
2. **Подбор ЦА** (алгоритм из «Кто ЦА»): топ-10 сообществ СПб → мужчины из СПб → состоят минимум в 3 из 10 →
   `score = k1·a + k2·b`, где `a` — доля сообществ, `b` — совпадение года начала обучения в ВУЗе СПб (±2 года).
   Подробности и оптимизации: `vk/audience.py`.
3. **Рассылка**: текст с реферальной ссылкой Яндекс Еды, 5 вариантов (случайно), пауза 40–90 с, лимит на аккаунт в сутки.
4. **Ответы** людей приходят в бота (проверка раз в 5 минут).

## Что нужно сделать один раз
1. Создать бота у @BotFather (`/newbot`), получить токен.
2. На сервере записать секреты (ввод скрыт):
   `sh vkpanel/set_secret.sh VKPANEL_BOT_TOKEN` и `sh vkpanel/set_secret.sh VKPANEL_ADMINS`
   (в `VKPANEL_ADMINS` через запятую имена без @ или числовые id двоих: `name1,name2`).
3. Создать Standalone-приложение VK (vk.com/apps?act=manage) и прислать его ID боту (Настройки → ID приложения).
4. Пополнить баланс DarkStore (dark.shopping), купить аккаунты кнопкой «DarkStore», получить токен каждого аккаунта
   (Аккаунты VK → «Как получить токен») и прислать токены боту.
5. Задать реферальную ссылку (Настройки → Ссылка) и запустить подбор ЦА, затем рассылку.

## Безопасность
- Бот отвечает только админам из `VKPANEL_ADMINS`, остальным молчит. Имя в Telegram привязывается к id при первом входе.
- Сообщения с токенами бот удаляет; логины и пароли в чате удаляются через 90 секунд.
- Покупка на DarkStore: только после подтверждения, не дороже `VKPANEL_MAX_SPEND` (по умолчанию 100) и не больше баланса.
- Рассылка в VK нарушает правила сети: аккаунты могут блокироваться. Лимиты по умолчанию консервативные (15 диалогов
  на аккаунт в сутки). Чтобы аккаунты не светились с адреса сервера, задайте `VK_PROXY` (socks5://…).

## Переменные .env
`VKPANEL_BOT_TOKEN`, `VKPANEL_ADMINS`, `VK_DB_PATH` (по умолчанию data/vk.db на сервере), `VK_REF_LINK` (запасная ссылка),
`VK_PROXY`, `VKPANEL_MAX_SPEND`, `DARKSTORE_API_KEY`.
